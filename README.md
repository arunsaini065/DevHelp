# DevHelp - Developer Quick Access Tool

DevHelp is a powerful utility app designed for Android developers to streamline their workflow. It provides instant shortcuts to frequently used system settings and automates tedious navigation tasks.

## 🚀 Features

- **Quick Shortcuts**: One-tap access to:
  - Wireless Debugging (ADB over Wi-Fi)
  - USB Debugging
  - Developer Options
  - Accessibility Settings
  - Wi-Fi Settings
  - App Info & Management
- **Special Access Manager**: Easily manage complex permissions like:
  - Display over other apps
  - Modify system settings
  - All files access
  - Notification access
  - Install unknown apps
- **Home Screen Shortcuts**: Pin any setting directly to your home screen with custom, recognizable icons for instant access.
- **Smart Automation**: Built-in Accessibility Service that:
  - Automatically scrolls to find settings.
  - Handles confirmation dialogs.
  - Navigates directly to QR pairing screens.
- **Modern UI**: Built with Jetpack Compose and Material 3 for a sleek, responsive experience.

## 🛠 How to Use

1. **Install the APK**: Download and install the app on your development device.
2. **Enable Accessibility Service**: For full automation (auto-scrolling and auto-enabling toggles), enable the "Dev Help Scanner Helper" in your device's Accessibility Settings.
3. **Pin Shortcuts**: Use the "Pin" icon next to any item on the dashboard to add a shortcut directly to your home screen.
4. **Quick Navigation**: Use the "Special Access" menu to manage high-level permissions without digging through system menus.

## 🔒 Permissions

This app requires:
- **Accessibility Service**: Used solely for automating navigation within the System Settings app (scrolling to find items and clicking pairing buttons).
- **Internet**: To provide the download link and potential updates.
